# MoreFlags

MoreFlags is a BentoBox addon that adds extra island settings.

## Flags

- Creeper explosions
- Wither explosions
- Phantom spawning
- Witch potion throwing
- Wind Charge launching
- Ghast fireballs
- Blaze fireballs

## Requirements

- Java 25
- Paper 26.1+
- BentoBox 3.7.0+

## Installation

1. Build or download the addon JAR.
2. Put it in the BentoBox `addons` directory.
3. Restart the server.

Configuration is stored in `plugins/BentoBox/addons/MoreFlags/config.yml`.

## Build

```sh
mvn clean verify
```

The JAR is created in the `target` directory.
